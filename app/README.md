# Native app

The Android, iOS and Windows app uses a bundled commentary catalog with matching
notes and search packs. The restored data includes Midrash Tanchuma, Midrash
Mishlei, Midrash Tannaim and both Mekhilta collections: 8,799 Midrash notes in
the 109-work catalog.

Catalog IDs belong to the native pack. The web database preserves its own
existing IDs during import. Pack identity checks keep downloaded notes and
search data aligned with the native catalog before the app adopts them.

See the [commentary pipeline](../data/sefaria/pipelines/perushim-view/README.md)
for reviewed verse maps, generation commands and managed/versioned pack delivery.

This is the Website (BE and FE) for the Bible on Site project.
It's implemented using Next.js 16 and react 19.

**Guidelines:**
- Use SSG wherever possible.
- Make sure each change is covered by a test.
- Check locally before pushing.

Next's current development validator incorrectly treats `robots.ts` and
`sitemap.ts` metadata exports as HTTP handlers. Only that generated development
validator is excluded from TypeScript. Run `next typegen` before standalone type
checks; its production route validator remains included, as does the validator
generated by `next build`.

Main features:
- **Bible Search**: Search for Bible verses and passages.
- **Book View**: Read the books of the Bible as interactive books.
- **Articles**: Learn articles related to the Bible.
- **Commentaries**: Learn Bible commentaries.
- **Recordings**: Listen to Bible recordings.

## Commentary data

The Sefaria pipeline includes Midrash Tanchuma, Midrash Mishlei, Midrash Tannaim
and both Mekhilta collections. Their 8,799 notes use validated biblical divisions
or reviewed passage-start dictionaries; supporting quotations remain in the text.

MySQL imports preserve existing web work IDs and retained published chapters.
Website builds replay the same import over a production commentary snapshot so
prerendered pages use matching IDs and content. See the
[commentary pipeline](../../data/sefaria/pipelines/perushim-view/README.md) for
the mapping, source guards and publication/rollback details.

After deployment, confirm the serving website version and compare the public SSR
catalog with the previously published work IDs. Check canonical commentary URLs
and ensure that both retained and newly generated work/chapter routes appear in
the live sitemap. A correct build snapshot alone does not verify the live site.

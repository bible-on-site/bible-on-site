# תוכנית מפת מקומות (תנכפדיה) — אתר

## מצב נוכחי

- המפה משתמשת ב־**Mapbox Standard** כאשר `NEXT_PUBLIC_MAPBOX_ACCESS_TOKEN` מוגדר בזמן בניית האתר. בפיתוח מקומי אפשר להגדיר אותו ב־`web/bible-on-site/.env.local` (הקובץ אינו נשמר ב־Git); תהליך אריזת האתר מקבל אותו מסוד GitHub Actions בשם `MAPBOX_PUBLIC_TOKEN`. ללא מפתח, רכיב Leaflet הקיים משמש כחלופה.
- סגנון Mapbox מסתיר גבולות מנהליים, סמלי נקודות עניין וסמלי אתרים בולטים. סימון סגול מציג את ערכי המקומות של תנכפדיה; לחיצה עליו פותחת קישורים לערכים.
- מתחת למפה מוצגת הודעת האתר על השימוש בספק חיצוני. ייחוס Mapbox ו־OpenStreetMap מוצג בתוך המפה.
- הערכים `eretz-yisrael` ו־`ירושלים` כוללים זיהוי מקום וקואורדינטות. קובצי הזריעה נמצאים ב־`data/mysql/tanahpedia_place_eretz_yisrael_data.sql` וב־`data/mysql/tanahpedia_place_jerusalem_data.sql`.
- **עמדת תוכן:** ארץ ישראל לפי התורה שייכת לעם ישראל; האתר אינו משרטט שכבת גבולות משלו, אלא רק סמני נקודות לערכים.

## סוגיית גבולות ושטחים (יהודה ושומרון, עזה)

שכבת הבסיס של ספק מפות חיצוני עשויה לכלול שמות או תווים שאינם תואמים את עמדת האתר. הסתרת הגבולות וסמלי נקודות העניין מפחיתה תווים כאלה, אך אינה מבטיחה שכל תיוג ייעלם בכל רמת תקריב.

**מטרת המוצר:** תצוגה עקבית עם עמדת האתר — **יהודה ושומרון ועזה כחלק מישראל** (ולא כישות נפרדת בשם "פלסטין" וכדומה), בכפוף להחלטות עורכי התוכן.

### כיווני פעולה אפשריים (לבחירה עתידית)

1. **שכבת גבולות/תווי חופים מותאמים**
   GeoJSON (או Vector Tiles) עם קו חוף וגבולות מנהליים לפי מדיניות האתר, מעל אריחי OSM או מעל רקע ניטרלי (למשל Carto Voyager / Stadia — עדיין ללא מפתח, תלוי בספק).

2. **ספק אריחים ניטרלי יותר**
   החלפת שכבת הבסיס לאריחים עם פחות תווים פוליטיים בקנה מידה מסוים (לא תמיד פותר את כל המקרים).

3. **אריחים עצמיים**
   Tile server פנימי או סט אריחים מקומי — עלות תפעול ותחזוקה גבוהות יותר.

4. **הערת עורכים**
   טקסט לצד המפה המבהיר שמדובר במיקומים גאוגרפיים בלבד ושגבולות מדיניים אינם מחייבים.
